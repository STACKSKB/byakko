Byakko Configurator for WordPress
==================================

Install the generated byakko-configurator.zip through Plugins > Add New > Upload Plugin, then activate it. Add a Shortcode block to a page containing:

    [byakko_configurator]

The shortcode shows the configurator in an iframe that grows with its content, so the WordPress page owns scrolling. A full-width, unboxed page template with no extra content spacing gives the keyboard room. The embed follows the page's font family and defaults to white surfaces and the application's indigo accent. Its optional appearance preferences are saved separately from the standalone client.

The plugin serves its bundled index.html from the same WordPress origin; the configurator runs locally in the visitor's browser. A small static presentation script sizes the iframe and keeps dialogs in the visible part of the page. No Node.js service or application API runs on the host. The link below the embed opens the standalone layout in a new tab.

WebHID requires HTTPS and a supported browser. Site or host permissions policies can still block HID or screen capture in the iframe. The new-tab link provides a full-page option and may avoid iframe-specific restrictions. Device writes and host capture in WordPress remain separate acceptance checks.

Linux visitors see a notice above the embed linking to bundled WebHID requirements. Client-side user-agent detection excludes Android and ChromeOS and works with shared page caches.
