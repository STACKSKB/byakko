Linux WebHID requirements

Use a browser supporting WebHID, such as Chrome or Chromium, and open the configurator over HTTPS. Select your Nia87 in the browser's permission prompt.

Linux must also grant your desktop user read/write access to the keyboard's configuration /dev/hidraw device. Browser permission alone cannot grant this access. If your system already grants it, no additional udev rule is needed.

Byakko provides a device-specific udev rule and permission helper. Follow the Linux installation instructions to build and install the helper and rule, reload udev rules, and reconnect the keyboard. The native desktop application itself is not required for WebHID.

The current rule covers the observed Nia87 configuration collection for USB 3151:4015. It does not cover PID 4011 or the separate onboard-change notification interface. Do not grant access to all hidraw devices to work around a mismatch.

Linux browser connection, writes and restoration remain unverified. The current rule does not establish automatic onboard synchronization on Linux.
