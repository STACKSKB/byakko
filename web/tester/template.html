How to use this keyboard tester

Choose your keyboard’s physical layout, size and printed legends. Click the keyboard or Start testing, then press keys. A tested key keeps a check mark after you release it. Hold several keys to see which arrive together. Tab moves focus out of the test; use Reset test to start again.

Compact keyboards use representative arrangements. Keys from another layer still appear in the event display even when they are absent from the picture. Legend choices change the picture; they do not change your operating system’s keyboard layout. Numpad and left/right modifier keys are tracked separately.

This checks events delivered to a focused browser page, not switches directly. Fn usually works inside the keyboard and sends no independent event. Your OS, browser or input method may intercept shortcuts or keys, including Print Screen and media keys. A missing event alone does not prove a faulty key. The simultaneous-key count describes this session’s received events, not a certified rollover limit.

The tester does not send or save your keystrokes. Its state stays in this page’s memory and disappears when you reload. No USB connection permission is needed.
